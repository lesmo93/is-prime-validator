# Validador de Números Primos (is-prime-validator)

Este es un paquete ligero de Node.js que proporciona una función sencilla y eficiente para determinar si un número dado es primo o no.

## Instalación

Como este es un proyecto local, solo necesitas asegurarte de tener el archivo `index.js` en tu directorio. Si alguna vez decides publicarlo en npm, los usuarios podrían instalarlo usando:

```bash
npm install is-prime-validator
```
